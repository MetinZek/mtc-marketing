# Davos Burgers — 30s menu video (Remotion)

1920×1080, 60 fps, 30 s. Copy, colors and timing live in `src/config.ts`.

```bash
npm install
npm run studio   # preview
npm run render   # -> out/davos-burgers.mp4
```

Scenes: Intro (icon + "Burger Menu") → 6 burger panels → menu board with rotating "House special" card → Davos house burger hero → logo outro.
